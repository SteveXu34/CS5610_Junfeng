# hw-server

Extend the in-class FastAPI demo into a backend for the
`hw-client` frontend that you already built.

## Assignment

1. [SETUP.md](SETUP.md) -- install Python, FastAPI, Postgres itself, and
   the Python driver (`psycopg2`) that connects to it.
2. [EXERCISE.md](EXERCISE.md) -- the three-step FastAPI walkthrough from class.
3. [DATABASE.md](DATABASE.md) -- complete this file. The `pg_dump` file
   from Step 7 is the actual deliverable; commit it and post the repo URL
   in Canvas.
4. We'll complete the rest -- API routes, connecting `hw-client`, testing --
   together in class.

## Learning objectives

* Set up a Python environment and a local Postgres database from the
  command line
* FastAPI basics (the in-class demo)
* `curl` for quick manual checks, independent of a browser
* `pytest` -- coming in class, alongside the API routes
